How it’s built

This page→Vercel serverless function→Gemini AI→7-day plan

The page sends your choices to a small server function. The function gives the AI a strategist role and asks for a structured plan, which the page turns into a readable calendar. The API key stays on the server, and the function limits input length and only accepts approved platform, goal and tone options.
